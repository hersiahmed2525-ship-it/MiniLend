How It Works

1. Create a Category

Make a category like "School" or "Friends".

2. Add a Card

Enter the item, the borrower's name, and the return date.

3. Track It

See exactly what is overdue and what has been returned.

About MiniLend

We built MiniLend because we were tired of losing our favorite books and tools to forgetful friends. It is a simple, Single Page Application built with HTML, CSS, JavaScript, and a JSON REST API.
